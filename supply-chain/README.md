# Supply Chain Datasets

Public datasets tracking software supply chain intelligence, runtime conditions, and parser quirks.

- `runtime-sbom-matrix.csv`: Ecosystem crosswalk of cloud runtime tools mapped to package URLs and ingestion engines.
- `parser-quirks.json`: Manifest syntax traps, YAML boolean gotchas, and parser edge cases.
- `deps-ossf.json`: OpenSSF Scorecard benchmarks and dependency lag metrics.
